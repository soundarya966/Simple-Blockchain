# Simple Blockchain using Java

## Overview
This project demonstrates a simple blockchain implementation using Java.

## Features
- Block creation
- SHA-256 hashing
- Proof of Work mining
- Blockchain validation
- Tampering detection

## Technologies Used
- Java
- SHA-256

## How to Run
1. Clone the repository
2. Open project in IntelliJ or VS Code
3. Compile all Java files
4. Run Main.java

## Output
- Mines blocks
- Displays blockchain
- Validates blockchain integrity

## Learning Outcomes
- Blockchain fundamentals
- Hashing
- Mining
- Immutable ledger
